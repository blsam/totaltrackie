# Changelog

## 1.1.0
- Added time transfer feature
- Added support for report generators for range of days instead of one
- Critical errors now displayed with a message box in addition to quietly reporting to log
- Last used report generator now remembered
- In-progress tasks which no completed by end of day, now automatically completed at end of day
- Added check for empty task name when created tasks
- Default report generator now support reporting for multiple days
